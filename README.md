# MERN Task Tracker - Frontend Client

React + Vite single-page application designed for practicing Git, GitHub collaboration, and Chrome DevTools.

## Tech Stack
- React 18
- Vite
- Modern Vanilla CSS with dark theme

## Quick Start
```bash
npm install
npm run dev
```

App runs on: `http://localhost:3000`
Backend expected at: `http://localhost:5000`
